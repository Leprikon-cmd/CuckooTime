Кто отвечает за приложение

Связаться с разработчиком приложения «Кукушка» можно по адресу поддержки. По вопросам конфиденциальности: kukushka.watch@yandex.ru.

Данные приложения

Приложение не требует регистрации. Оно не передаёт разработчику данные об использовании, не содержит рекламных и аналитических SDK и не отслеживает вас между приложениями или сайтами.

Выбранный циферблат, ручное время, запас завода, состояние хода, параметры звука и оповещений сохраняются локально на устройстве. Для расширения циферблата часть состояния хранится в общей локальной области приложения и расширения. Эта область не является сервером и не отправляет данные разработчику.

Оповещения

По вашему разрешению приложение планирует локальные уведомления. Разрешение можно изменить в системных настройках. Для этих оповещений приложение не передаёт расписание на сервер разработчика.

Хранение и удаление

Локальное состояние хранится для продолжения работы часов между запусками. Удалением приложения и его локальных данных управляет watchOS. Системные резервные копии, если они включены, обрабатываются Apple по её правилам. У разработчика нет удалённой копии ваших настроек, которую можно было бы запросить или удалить.

Обращения в поддержку

Если вы сами отправляете письмо в поддержку, издатель получает ваш email и содержимое письма. Эти сведения используются, чтобы ответить и разобраться с обращением. Не отправляйте пароли, платёжные сведения и другие лишние персональные данные. По запросу на адрес поддержки обращение удаляется, кроме сведений, которые необходимо сохранить для выполнения обязанностей по закону.

Этот сайт

Страницы поддержки не содержат добавленной нами аналитики, рекламных скриптов и форм отслеживания. При размещении на GitHub Pages технические сведения о посещении могут обрабатываться GitHub как провайдером хостинга по его собственной политике. Это отличается от локальной работы приложения.

Изменения
